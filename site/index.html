Open source · Agents in your chat

Your chat is the control room for coding agents.

Give an order in Discord. A coding agent gets its own workspace and reports back in the thread. Run several at once, and keep up from your phone.

Claude Code + Codex · Your machine, your existing CLI login

Parallel work, with a place for everything

More agents. A clear thread for each.

01 / WORKSPACE

A thread is a workspace

Each thread owns an agent session and a working directory with its own clone. Give separate tasks to separate threads and follow each conversation on its own.

02 / YOUR AGENTS

Use what you already have

Run the Claude Code and Codex CLIs you have installed, with your existing subscription or API login. Authentication stays with the CLI; hataori runs the agent as you.

03 / SUPERVISOR

A supervisor for the channel

An optional Claude Code supervisor watches turn results, keeps notes and reminders, and can propose or start follow-up work. You set its access, autonomy and budgets. A Codex supervisor is not supported yet.

How it compares

Choose where you want to work.

Orca and cmux put agents side by side in a dedicated app on your machine. hataori makes a chat thread the place you give orders and get replies.

Orca

An agent development environment with parallel worktrees and an integrated app. It also offers remote runtimes, mobile companions and bots that accept jobs from services including Slack.

Website ↗Source ↗

cmux

A native macOS terminal with vertical tabs, split panes and notifications for agents. It supports SSH workspaces and offers an iOS companion in beta.

Website ↗Source ↗

hataori

Discord threads are the primary interface. Each thread maps to one session and working directory, with an optional channel supervisor and a web dashboard.

Source ↗

Based on their own public websites and repositories, read 27 November 2026. Orca’s onorca.dev redirects to orca.dev. These are different workflows; both alternatives also support work away from the desktop.

In development

What you can use today.

Implemented

  • Discord threads with Claude Code and Codex.
  • Progress and final replies, questions, file handoffs and Stop controls.
  • Sessions that survive daemon restarts and resume after sleeping.
  • A web dashboard and an optional Claude Code supervisor.
  • Linux and macOS, covered by CI. Windows is not currently supported.

Still ahead

  • Slack is next. Microsoft Teams is planned.
  • No installer or release binaries yet. Build from source; macOS CI artifacts are also available.
  • Setup requires an installed, logged-in agent CLI and a Discord bot.
