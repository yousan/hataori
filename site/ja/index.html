Open source · Agents in your chat

いつものチャットを、
エージェントの司令室に。

Discord で依頼すると、エージェントが専用の作業場所で仕事を始め、同じスレッドに報告します。複数のタスクを並行して進め、外出先ではスマホから続きを。

Claude Code + Codex · 自分のマシンで、ログイン済みの CLI をそのまま

並行して進めても、会話は混ざらない

仕事ごとに、エージェントの居場所を。

01 / WORKSPACE

スレッドごとに作業場所を

ひとつのスレッドが、ひとつのセッションと専用のクローンを持ちます。別の仕事は別のスレッドへ。それぞれの会話を追いながら、並行して進められます。

02 / YOUR AGENTS

使っているエージェントを、そのまま

インストール済みの Claude Code と Codex を、今のサブスクリプションや API のログインで動かします。認証は CLI に任せ、hataori はあなたのユーザーでエージェントを起動します。

03 / SUPERVISOR

チャンネルを見守る supervisor

任意で有効にする Claude Code の supervisor が、各ターンの結果を見て、メモやリマインダーを残し、次の仕事を提案・開始します。権限、自律性、予算は設定で制限できます。Codex の supervisor は未対応です。

他のツールとの違い

どこから仕事を進めたいか。

Orca と cmux は、自分のマシン上の専用アプリにエージェントを並べます。hataori はチャットのスレッドを、指示と報告の窓口にします。

Orca

複数の worktree とエージェントをまとめて扱う開発環境。リモート実行やモバイルアプリに加え、Slack などから仕事を受ける bot も提供しています。

公式サイト ↗ソース ↗

cmux

縦タブ、分割ペイン、エージェントの通知を備える macOS ネイティブのターミナル。SSH での作業に対応し、iOS アプリもベータ提供されています。

公式サイト ↗ソース ↗

hataori

主な操作場所は Discord のスレッド。スレッドごとにセッションと作業ディレクトリを持ち、必要に応じてチャンネルの supervisor や Web ダッシュボードを使えます。

ソース ↗

各ツールの公式サイトと公開リポジトリを 2026年11月27日に確認。Orca の onorca.dev は orca.dev に転送されます。どちらもデスクトップ以外からの利用に対応しています。違いは、日々の仕事をどこで進めるかです。

実装済み

  • Discord のスレッドで Claude Code と Codex を実行。
  • 進捗と最終回答の投稿、質問への回答、ファイルの受け渡し、停止操作。
  • デーモンの再起動をまたぐセッションの維持と、スリープ後の再開。
  • Web ダッシュボードと、任意で有効にする Claude Code の supervisor。
  • Linux と macOS を CI でテスト。Windows は現在未対応。

これから

  • 導入には、ログイン済みのエージェント CLI と Discord bot の準備が必要です。
